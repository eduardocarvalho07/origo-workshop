📋 Como Usar

Fase 1: Votação de Objetivos

Cadastre os diretores e deixe que cada um sugira objetivos para as três dimensões:

  • Eficiência
  • Clientes
  • Expansão/Novos Negócios

Todos votam nas melhores opções.

Fase 2: Ajuste e Refinamentos

Para os objetivos mais votados, você pode:

  • Solicitar refinamentos específicos
  • IA gera 5 opções melhoradas
  • Selecione a melhor opção refinada

Fase 3: Mapa de Objetivos Estratégicos

Visualize os 3 objetivos eleitos de forma profissional, prontos para apresentação executiva.

Fase 4: Ambição Final

Cada diretor escreve sua ambição para a Órigo e todos votam na melhor. Incorpora ao mapa final.

🔐 Acesso de Administrador
Clique no botão ⚙️ (canto inferior direito) e use a senha: Falconi2024

💾 Seus Dados

Todos os dados são salvos automaticamente no navegador. Você pode:

  • Exportar em JSON para backup completo
  • Exportar em CSV para análise em Excel
  • Imprimir o resumo final
